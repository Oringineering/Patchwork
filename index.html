A FEW THINGS TO KNOW

Before your first repair.

What happens to my code?+

The target source, bug report and context files you select are sent to Nebius Token Factory for model inference. Patchwork holds the workspace in this browser tab and does not write uploads to server disk. Closing or refreshing the tab clears the workspace. Download it before leaving.

Does it run or automatically apply changes?+

No code execution takes place. Python and JSON receive syntax checks. You decide whether to accept a proposal into the browser workspace and download it. Your local files are not modified.

What can I upload?+

A ZIP up to 2 MB, containing up to 40 supported text files. Common source, JSON, Markdown and YAML files are supported. Dependencies, binary files and common secret files are skipped and listed. Exported ZIPs contain the supported workspace files only.
